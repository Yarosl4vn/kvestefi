# 🌐 Квестефи (Kvestefi) — PWA & Web Платформа

> **Образовательная экосистема ReadySquad (г. Мытищи, Московская область)**  
> Интеллектуальные квесты, тренажёр подготовки к ОГЭ/ЕГЭ (11 550 заданий), межшкольные соревнования для всех 39 школ г. Мытищи, дружеские забеги 1 на 1 и цифровой пропуск **Ready ID**.

📱 **Официальный сайт & PWA:** [https://yarosl4vn.github.io/kvestefi/](https://yarosl4vn.github.io/kvestefi/)

---

## 🚀 Возможности платформы

- 🍏 **PWA для iPhone (iOS):** установка в 1 клик на экран «Домой» через Safari, запуск во весь экран без рамок браузера, виброотклик и оффлайн-кэш.
- 💻 **Десктопная версия для ПК:** адаптивный интерфейс с боковой панелью навигации, горячими клавишами (`1..4`, `Enter`) и возможностью установки на рабочий стол через Chrome / Edge.
- 📚 **Банк из 11 550 заданий по 11 предметам:** Математика, Русский язык, Физика, Информатика, История, Биология, Химия, Обществознание, География, Английский язык, Литература (по 1050 задач на каждый предмет).
- 🏛️ **Межшкольные соревнования г. Мытищи:** 10 городских турниров, 3 тура, сводный рейтинг всех 39 школ городского округа Мытищи, официальное Положение о соревнованиях (п. 1.1, 1.2...).
- ⚔️ **Дружеские забеги (1 на 1):** блиц-дуэли на скорость по таймеру (20 сек) против смарт-бота или друзей.
- 🛡️ **Цифровой пропуск Ready ID:** уровневая система от 1 до 2000 уровней, титулы (от «Новичок» до «Ветеран Квестефи» и «Абсолютная Легенда ReadySquad»), бейджи и достижения.
- 💬 **Чат и техподдержка:** сообщения в реальном времени, тикеты поддержки с префиксами «ОДОБРЕНО» и «ЗАКРЫТО», рассылка разработчиков.
- 🛠️ **Панель разработчика:** живой поиск пользователей от 2 букв, блокировка с пресетами (7, 15, 30... дней), назначение классного руководителя (выбор класса 1..11 и буквы А..Д).

## 📲 Как установить на iPhone / iPad

1. Откройте **Safari** на iPhone и перейдите на сайт:  
   👉 **[https://yarosl4vn.github.io/kvestefi/](https://yarosl4vn.github.io/kvestefi/)**
2. Внизу экрана нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»**. Иконка «Квестефи» появится на рабочем столе!

---

## 💻 Установка на ПК (Windows / macOS)

1. Откройте сайт в Google Chrome или Microsoft Edge.
2. В правой части адресной строки нажмите кнопку **«Установить приложение»** (значок монитора).
3. Приложение откроется в отдельном окне и создаст ярлык на рабочем столе.

---

## 🛠 Локальный запуск разработчика

```bash
# Клонировать репозиторий
git clone https://github.com/Yarosl4vn/kvestefi.git
cd kvestefi

# Запустить локальный сервер
python start_server.py
# или дважды кликнуть start_web.bat в Windows
```
